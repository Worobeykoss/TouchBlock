# Блокировка касаний

[English](README.md) | **Русский**

Android-приложение, которое отключает сенсор в выбранных прямоугольных областях экрана.
Полезно при «фантомных» нажатиях на повреждённом экране или чтобы закрыть часть экрана от случайных касаний.

- Зон может быть несколько. Их рисуют пальцем прямо поверх текущего экрана, потом двигают и растягивают.
- Работает поверх всего: в любых приложениях и Настройках, на строке состояния, кнопках навигации, клавиатуре и экране блокировки.
- Зона привязана к физическому участку экрана и при повороте телефона остаётся на месте.
- Зоны можно подсвечивать красным или сделать невидимыми.
- Уведомление с кнопками «Пауза», «Зоны» и «Выключить».
- Интерфейс на английском и русском.

Требуется Android 8.0 и новее.

## Установка

1. Скачайте `TouchBlock.apk` из [последнего релиза](../../releases/latest) и установите его.
2. Откройте приложение и нажмите «Открыть „Специальные возможности“». Включите службу «Блокировка касаний».
3. **Android 13+:** для приложений, установленных из APK, а не из магазина, переключатель сначала будет неактивен
   («ограниченная настройка»). Попробуйте включить службу один раз, затем откройте «Сведения о приложении» → ⋮ →
   разрешите ограниченные настройки и включите службу снова.
4. Нажмите «Настроить зоны», нарисуйте зоны и включите блокировку.

## Как работает

Блокировку держит служба специальных возможностей (`BlockerService`). Она ставит прозрачные окна
размером с зоны типа `TYPE_ACCESSIBILITY_OVERLAY`. Касание, начавшееся внутри зоны, достаётся этому окну
и дальше не передаётся. Касания вне зон работают как обычно.

Почему служба спецвозможностей, а не разрешение «Поверх других приложений»: начиная с Android 12,
обычные наложения (`TYPE_APPLICATION_OVERLAY`) система прячет на многих экранах Настроек,
в диалогах разрешений, в установщике и в любых приложениях, которые об этом просят (`setHideOverlayWindows`).
Окна службы спецвозможностей под это правило не попадают. Кроме того, они лежат выше строки состояния,
панели навигации, клавиатуры и экрана блокировки.

Служба не подписана ни на какие события спецвозможностей, не читает содержимое экрана и не обращается к сети.

Зоны хранятся в долях экрана в естественной ориентации устройства, поэтому при повороте остаются на том же физическом участке стекла.

## Если зона перекрыла что-то нужное

- Нажмите «Пауза» или «Выключить» в уведомлении.
- Заранее включите быстрый запуск службы: «Специальные возможности» → «Блокировка касаний» → ярлык кнопками громкости.
  Тогда службу можно выключить, если зажать обе кнопки громкости на 3 секунды.
- После перезагрузки служба не работает до первой разблокировки, поэтому ввести PIN-код зоны не помешают.

## Ограничения

- При навигации жестами свайп снизу («домой») обрабатывает сама система раньше любых окон.
  Жест «назад» от края экрана гасится внутри зоны, но система делает это не больше чем для 200dp по высоте у каждого края.
  Если это мешает, лучше включить навигацию тремя кнопками: их зона перекрывает полностью.
- Касание, начатое вне зоны, продолжает работать, даже если палец заходит в зону.

## Сборка

Нужны JDK 17 и Android SDK (platform 35, build-tools 35.0.0). Путь к SDK укажите в `local.properties`:

```
sdk.dir=C:/path/to/Android/Sdk
```

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Если на Windows сборка падает с `Unable to establish loopback connection`, значит путь к временной папке слишком длинный для JDK.
Задайте короткий `TEMP`/`TMP`, например `C:\tmp`.

## Структура

| Файл | Что делает |
|---|---|
| `BlockerService.kt` | Служба спецвозможностей: окна-блокираторы, уведомление, реакция на поворот экрана |
| `ZoneEditorView.kt` | Полноэкранный редактор зон: рисование, перемещение, изменение размера |
| `ScreenGeometry.kt` | Перевод зон между экранными координатами и естественной ориентацией |
| `MainActivity.kt` | Экран настроек, включение службы |
| `NotificationActionReceiver.kt` | Кнопки «Пауза» и «Выключить» в уведомлении |
| `EditZonesActivity.kt` | Невидимая активность для кнопки «Зоны» в уведомлении (сворачивает шторку) |
